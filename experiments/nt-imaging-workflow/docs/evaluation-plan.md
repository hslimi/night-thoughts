# Evaluation plan

No clinical evaluation or diagnostic benchmark was performed. Current tests verify workflow behavior, schema validity, imaging/parser controls, PHI-screening failure behavior, security invariants, and real endpoint interoperability on artificial pixels. Pixel snapshots do not establish clinical image equivalence.

A later governed evaluation should define intended use and representative retrospective data with a radiologist-designed protocol. Separate structural validity, visual-consistency usefulness, writing quality, and clinical endpoints. Measure failure modes, subgroup behavior, uncertainty, reviewer time, override/rejection rates, and interoperability errors. Preserve versioned datasets, model hashes/IDs, prompts, policy, and audit records. Compare against a defined baseline and obtain independent clinical, privacy, security, legal, and regulatory review before any prospective silent-mode study.

Public research images are optional. Record the exact asset URL, dataset, authoritative terms, date, hash, and limitations before use; do not assume NIH ChestX-ray14 licensing. The automated baseline uses synthetic inputs and does not require a large dataset download.
