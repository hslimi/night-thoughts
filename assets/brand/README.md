# Night Thoughts Brand Assets

## Logo Usage

- **Light backgrounds:** use `night-thoughts-for-light-background.png`.
- **Dark backgrounds:** use `night-thoughts-for-dark-background.png`.
- **Avatars and small sizes:** use `night-thoughts-icon.png`. It contains only the crescent, face, and stars, without the wordmark or tagline.
- **GitHub social previews:** use `github-social-preview.png`, a balanced dark-background composition sized 1280×640.

Preserve the full logo's aspect ratio and clear space. Do not stretch it; always resize it proportionally.

## Raster and Future Source Formats

The supplied PNGs are currently raster assets. No genuine vector master is included.

Recommended future source formats are:

- a genuine SVG master, treated as a separate design task rather than assuming automated tracing will produce a clean vector;
- high-quality PNG exports for web and repository use;
- PDF for document sharing.
